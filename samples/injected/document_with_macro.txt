DOCUMENT WITH SIMULATED MACRO
============================

This is a text file that simulates a document with a malicious macro.
In a real scenario, this would be a .docx or .xlsx file with an embedded macro.

The following is a representation of what a malicious macro might look like:

This file is for testing security scanning tools only.
No actual malicious code is present or executed.
